# WhatsApp Summarizer

Este é um aplicativo web para resumir conversas do WhatsApp e enviar resumos automáticos.

## Como iniciar

1. Execute `npm install` para instalar as dependências.
2. Execute `npm start` para iniciar o servidor.
3. Acesse `http://localhost:3000` no navegador.

## Funcionalidades
- Login simples (admin/senha123)
- Configurações para grupo, horários e chaves de API
- Gerar resumo manualmente
- Historico de resumos
